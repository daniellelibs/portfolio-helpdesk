# Help Desk Portfolio

This repository documents a hands-on lab I built simulating the IT support environment of a small company, including Windows Server / Active Directory administration, user and group management, and simulated support tickets.

## About me
Entry-level IT support / help desk candidate. Google Cybersecurity Certified. Currently building practical experience through self-directed labs while applying for help desk / technical support roles.

## What's in this repo

- **/tickets** — Simulated support tickets, documenting real troubleshooting scenarios (password resets, account lockouts, permission issues), written in a professional ticket format.
- **/screenshots** — Screenshots from the lab environment showing Active Directory configuration, user/group management, and Group Policy settings.

## Lab environment

- Windows Server 2022 (Active Directory Domain Services, promoted to Domain Controller)
- VirtualBox for virtualization
- Organizational Unit and user accounts created and managed via Active Directory Users and Computers
- Account Lockout Policy configured via Group Policy Management

## Skills demonstrated

- Active Directory: OU structure, user/group creation and management
- Password resets and account unlock procedures
- Group Policy configuration (account lockout policy)
- NTFS permissions and access troubleshooting
- Ticket documentation and professional communication
