# Ticket #001 — Password Reset

**User:** Maria Silva
**Category:** Account Access
**Priority:** Medium
**Status:** Closed

## Reported Issue
"I forgot my password and can't log into my computer."

## Diagnosis
Verified the account in Active Directory Users and Computers to confirm the account was active and not locked.

## Resolution
Reset the password via right-click > **Reset Password**, and enabled **"User must change password at next logon"** to force the creation of a new secure password on the next login attempt.

## Resolution Time
3 minutes

## Tools Used
Active Directory Users and Computers (ADUC)
